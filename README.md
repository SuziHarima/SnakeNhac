# Snake Game

Jogo da cobrinha

## Para iniciar

Pode ser iniciado diretamente pelo browser.

## Sobre o programa

Criado utilizando JS puro sem nenhuma lib.
Animações com CSS a partir de imagens e gifs e lógica com DOM.


## Melhorias

- Deixar score sempre com pelo menos duas casas decimais
- Aprimorar pressionamento de teclas e resposta em jogo
